# knowledge-to-wiki

Claude Code skill: превращает методичные источники (книга, курс, транскрипт, статья, PDF — один или несколько) в связную **LLM-вики** по паттерну [Андрея Карпаты](https://gist.github.com/karpathy) — атомарные страницы-концепты с навигацией от `index.md`.

Чем отличается от заметок или пересказа:

- **Ничего не выдумано** — каждое утверждение подкреплено дословной цитатой из источника с номерами строк.
- **Связи названы** — ссылка помечена: предпосылка, следующий шаг, противоположность, частный случай, родительская тема.
- **Просто markdown** — без привязки к инструменту, читается любым агентом или человеком, живёт в git.

## Установка

Дайте Claude Code ссылку на репозиторий и попросите установить скилл. Дальше он срабатывает сам.

## Режимы

| | |
|-|-|
| **build** | собрать вики из источника с нуля |
| **enrich** | добавить новый источник, не ломая и не дублируя готовое |
| **query** | ответить с цитатой; на «как сделать X» сначала уточнит детали |
| **lint** | найти битые ссылки, страницы-сироты, разъехавшиеся цитаты |

«собери вики по этой книге» · «добавь транскрипт в вику» · «что в материале про X» · «прогон lint»

## Что создаёт

```
<wiki-проект>/
├── index.md   ← навигация + точка входа
├── schema.md  ← контракт страницы
├── log.md     ← журнал операций
├── sources/   ← сырьё, неизменяемое
└── wiki/      ← страницы-концепты, плоско, кросс-ссылаются
```
